# LuvKimchi-Macro

Desktop automation utility developed using C# and Windows Forms.

## Purpose

Created to automate repetitive keyboard actions and reduce manual interaction during long-running tasks.

## Features

* Custom key binding
* Scheduled key triggering
* Countdown timer
* Auto close
* Always-on-top mode

## Technologies

* C#
* Windows Forms
* Visual Studio

## Status

Personal project developed for practical use and workflow automation.
